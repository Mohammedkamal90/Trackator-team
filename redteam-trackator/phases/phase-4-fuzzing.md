## Plugin: Realism Check (BLOCK GATE #3)

**Purpose**: Filter out fuzz findings that aren't reachable on real mainnet state.

```javascript
function realismCheck(fuzzFinding, context) {
    // Check 1: Does finding require unrealistic state?
    if (requiresUnrealisticState(fuzzFinding, context)) {
        return { verdict: 'unrealistic', keepForReview: true };  // BLOCK GATE
    }
    
    // Check 2: Does finding require trusted role action?
    if (requiresTrustedRoleAction(fuzzFinding, context)) {
        return { verdict: 'operational_error', keepForReview: false };
    }
    
    // Check 3: Is there enough capital/liquidity?
    if (requiresExcessiveCapital(fuzzFinding, context)) {
        return { verdict: 'impractical', keepForReview: true };
    }
    
    return { verdict: 'realistic', proceedToForkTest: true };
}
```

**Verdict Outcomes**:
| Verdict | Meaning | Action |
|---------|---------|--------|
| `unrealistic` | Requires unachievable mainnet state | Keep for manual review |
| `operational_error` | Requires trusted role action | Discard |
| `impractical` | Requires excessive capital ($M+) | Keep for whale attack review |
| `realistic` | Achievable on mainnet | Proceed to fork testing |

## Plugin: Disproof Engine (v2.0)

**Purpose**: Attempt to **DISPROVE** fuzz findings before accepting them as vulnerabilities.

> *"A finding that survives disproof attempts is stronger than one that was never challenged."*

### Disproof Strategies (4 Core Attempts)

```javascript
function disproofEngine(fuzzFinding, context) {
    const attempt = { findingId: fuzzFinding.id, disproofEvidence: [] };
    
    // ATTEMPT 1: Guard Code Search - Look for require/assert/check patterns
    const guardCode = searchForGuardCode(fuzzFinding, context);
    if (guardCode.found && guardCode.isEffective) {
        return { ...attempt, disproofResult: 'DISPROVED', residualRisk: 'low' };
    }
    
    // ATTEMPT 2: Semantic Analysis - Does pattern actually lead to loss?
    const semantic = analyzeSemantics(fuzzFinding, context);
    if (semantic.isFalsePositive && semantic.confidence > 0.8) {
        return { ...attempt, disproofResult: 'DISPROVED', residualRisk: 'low' };
    }
    
    // ATTEMPT 3: Historical Pattern Cross-Check
    // Has similar pattern been disproved before? (uses context.evidence history)
    
    // ATTEMPT 4: Invariant Consistency Check
    // Would exploiting this violate safety invariants that PROTECT users?
    
    // FINAL DETERMINATION
    if (attempt.disproofEvidence.length === 0) {
        return { ...attempt, disproofResult: 'NOT_DISPROVED', residualRisk: 'medium-high' };
    }
    return { ...attempt, disproofResult: 'CANNOT_DETERMINE', residualRisk: 'medium' };
}
```

### Disproof Results

| Result | Meaning | Residual Risk |
|--------|---------|---------------|
| `DISPROVED` | Finding is likely false positive | Low |
| `NOT_DISPROVED` | No counter-evidence found | Medium-High |
| `CANNOT_DETERMINE` | Some evidence but inconclusive | Medium |

### Local Classification Fallback

When no Trackator evidence entry matches, use local scoring:

```javascript
function classifyFindingV21(finding, context) {
    let score = 50;  // Base uncertainty
    
    if (finding.trackatorEvidence?.matrixEntry) score += 15;
    if (finding.prerequisiteChain?.length >= 4) score += 10;
    if (finding.estimatedDifficulty === 'easy') score += 10;
    if (finding.trackatorEvidence?.source === 'criticalFindings[]') score += 15;
    
    if (finding.disproofResult === 'DISPROVED') return { class: 'false-positive', confidence: 10 };
    if (score >= 85) return { class: 'reachable-bug', confidence: score };
    if (score >= 60) return { class: 'potential-bug', confidence: score };
    if (score >= 30) return { class: 'insufficient-evidence', confidence: score };
    return { class: 'cannot-determine', confidence: score };
}
```

### Verdict Derivation Logic

```javascript
function deriveVerdict(calibration) {
    if (['false-positive', 'by-design'].includes(calibration.disproofResult)) return calibration.disproofResult;
    if (calibration.classification === 'reachable-bug' && calibration.reachability === 'reachable') {
        return calibration.proofRequirements.met >= 7 ? 'confirmed-vulnerability' : 'potential-vulnerability';
    }
    if (calibration.classification === 'potential-bug' && calibration.confidenceBreakdown.overall >= 70) {
        return 'potential-vulnerability';
    }
    if (calibration.remainingUnknowns?.length > 3) return 'cannot-determine';
    return 'deferred';
}

function deriveRecommendedAction(calibration) {
    const actionMap = {
        'confirmed-vulnerability': 'immediate-fix',
        'potential-vulnerability': 'short-term-investigation',
        'false-positive': 'dismiss',
        'by-design': 'accept-risk',
        'cannot-determine': 'escalate-to-auditor',
        'deferred': 'defer'
    };
    return actionMap[calibration.finalVerdict] || 'defer';
}
```

## Classification Classes Reference

| Class | Description | Action |
|-------|-------------|--------|
| `confirmed-vulnerability` | Reachable, exploitable, high-confidence bug | Report as P0/P1 finding |
| `potential-vulnerability` | Likely exploitable but needs manual verification | Report with caveats as P2 |
| `false-positive` | Theoretically matches pattern but not actually exploitable | Discard with documentation |
| `by-design` | Looks like bug but intentional security trade-off | Note in methodology |
| `informational` | Not a bug but worth noting (code smell, anti-pattern) | Appendix only |
| `cannot-determine` | Insufficient evidence to classify | Queue for manual review |
